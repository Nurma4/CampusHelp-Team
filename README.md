# CampusHelp – TeamXX
Project management assignment pack. Replace TeamXX and Student A/B/C placeholders with actual details.

## GitHub setup sequence
1. Create repository `CampusHelp-TeamXX` (private, README enabled).
2. Invite the other two members as collaborators.
3. Upload the contents of this pack into the repository, preserving folders.
4. Create milestones M1–M4 with real due dates (Day 2, 4, 7, 10).
5. Create the labels listed in `docs/github-setup.md`.
6. Create the 12 Issues using `docs/issues.md`, assign owners and milestones.
7. Create a GitHub Project board with Todo, In Progress, Done; add all issues.
8. Add Priority, Estimated Hours, Actual Hours, Start Date, Due Date fields.
9. Create Table and Roadmap views.
10. Each member creates a branch, contributes a file, submits a PR, and reviews another member's PR.
11. Record Day 2, 5, and 8 monitoring updates.
12. Complete the change request, test cases, closure report, and consolidate the PDF.

## Team placeholders
- Student A: Project Manager
- Student B: Business Analyst & Designer
- Student C: Risk & Quality Coordinator

See docs for ready-to-upload content. This pack provides project documentation; actual GitHub activity and evidence screenshots must be created by the team.
