# Work Breakdown Structure (WBS)

**1.0 CampusHelp Project**
- **1.1 Initiation**
  - 1.1.1 Project charter
  - 1.1.2 Requirements and stakeholder analysis
  - 1.1.3 WBS
- **1.2 Planning**
  - 1.2.1 Schedule, dependencies and budget
  - 1.2.2 Wireframes
  - 1.2.3 Risk register and quality plan
- **1.3 Execution**
  - 1.3.1 Student request interface
  - 1.3.2 Administrator dashboard
  - 1.3.3 Prototype testing
- **1.4 Closure**
  - 1.4.1 Change control
  - 1.4.2 Final verification
  - 1.4.3 Project closure and report

## Work package descriptions
| Work package | Deliverable |
|---|---|
| Charter | Project purpose, scope, stakeholders, constraints and success criteria |
| Requirements | Functional requirements and stakeholder needs |
| WBS | Hierarchical breakdown of work |
| Schedule/budget | Task timing, dependencies, effort and simulated cost |
| Wireframes | Student and admin screen layouts |
| Risk/quality | Risk register and quality/test plan |
| Student interface | Submission and tracking mockup |
| Admin interface | Assignment/status dashboard mockup |
| Testing | Six documented test cases and results |
| Change control | Request, impact analysis and decision |
| Verification | Review of evidence and completion |
| Closure | Final report and lessons learned |
